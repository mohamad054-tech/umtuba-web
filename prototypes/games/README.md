# نماذج ألعاب UMTUBA

## ما هي هذه الملفات

هذه نماذج ألعاب مبنية على محرك واحد مشترك. كل ملف يعرض مجموعة ألعاب فوق نفس الأساس (النقاط، المؤقّت، لوحة المتصدّرين)، دون دمج في المنصة بعد.

## الملفات

| اسم الملف | الألعاب التي يحتويها | القسم في المنصة |
| --- | --- | --- |
| `01-engine-quiz-sudoku.html` | اختبار الدرس، سودوكو | التعليم / الألعاب |
| `02-world-games.html` | خمّن المدينة، تحدّي المعالم، جامع المدن | World |
| `03-store-and-general-games.html` | خمّن السعر، عجلة الخصم، تحدّي السلة، الذاكرة، إكس أو، كلمة السر | المتجر / الألعاب |
| `04-world-games-2.html` | تخمين العلم، المسافة بين مدينتين، أي دولة أكبر | World |
| `05-store-games-2.html` | أي منتج أرخص، رتّب حسب السعر، خمّن الخصم | المتجر |
| `06-learning-games.html` | سؤال سريع، ترتيب الخطوات، وصّل المصطلح، تحدي المفردات، أكمل الجملة | التعليم |
| `07-casual-games.html` | سوليتير، ٢٠٤٨، ثعبان، مطابقة الأشكال، سباق الكتابة، برج هانوي، أونو مبسّطة | الألعاب |

## تنبيهات

- هذه نماذج للتجربة، غير مدمجة بالمنصة.
- النقاط تُحفظ في ذاكرة المتصفح فقط وتضيع عند إغلاق الصفحة.

## ملاحظات للدمج لاحقاً

- عند الدمج يُستبدل قسم التخزين في المحرك بجداول Supabase، وهو موحّد في المحرك فيكفي تغييره مرة واحدة لكل الألعاب.
- ألعاب World تحتاج مدينة حقيقية لكل فيديو؛ حالياً كل فيديو مدينته UMTUBA ودولته Worldwide، فتعمل ببيانات تجريبية.
- عجلة الخصم بجوائز مضمونة بلا خسارة، تجنّباً لتصنيفها كيانصيب.
