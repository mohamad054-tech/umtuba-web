# Learning partner one-pager (internal)

Purpose: explain how a future Learning partner would be reviewed. Not an offer letter.

## Provider types

- UMTUBA_ORIGINAL — first-party courses owned by UMTUBA
- PARTNER — later contracted catalogs
- EXTERNAL — metadata / enrollment-off-platform listings

## What a later partner must grant in writing

- METADATA_DISPLAY_ALLOWED
- CONTENT_HOSTING_ALLOWED and VIDEO_HOSTING_ALLOWED if UMTUBA hosts media
- ENROLLMENT_ALLOWED
- PAYMENT_ALLOWED only if UMTUBA would collect
- AI_USAGE_ALLOWED — default FALSE. UMTUBA will not ingest partner lessons into AI Tutor without an explicit grant
- CERTIFICATE_INTEGRATION_ALLOWED — UMTUBA certificates represent UMTUBA only unless a later contract says otherwise

## What UMTUBA will not do now

- Copy external courses.
- Fabricate partner or university instructors.
- Publish UMTUBA Originals to Production automatically.
- Issue an UMTUBA certificate for partner content when certificate ownership is not UMTUBA.
