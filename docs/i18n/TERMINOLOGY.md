# UMTUBA web terminology — 13 locales

Brand **UMTUBA** stays Latin in every locale. Do not transliterate (no أمتوبة / أم طوبا).

`PORTUGUESE_VARIANT` = **pt-BR** (Salvar, Carregando, Você, Seguindo, estoque, pedidos). Not pt-PT.

`CHINESE_VARIANT` = **zh-CN** (Simplified). `zh-TW` / `zh-Hant` do not collapse. World city-copy slot remains `zh`.

## Branding decisions (deep linguistic QA 2026-08-19)

| Term | Decision | Why |
| --- | --- | --- |
| **Watch** | Translate the surface label in every locale | Official glossary. Leaving English in fr/es/de/pt only because a prior cut did so is not defensible. It is a video tab, not a coined product name. |
| **Hello City** | Keep English **Hello City** in all 13 locales | Coined feature name. Literal “hello, city” strings read as machine translation (你好城市, こんにちは、都市, 안녕, 도시). Help text stays localized. |
| **UMTUBA** | Latin only | Style guide. Arabic chrome no longer uses أمتوبة / أم طوبا. |
| **World Discovery / World Search** | Keep English domain names where they name the product surface | Internal product name, not a common verb. Surrounding sentence is localized. |
